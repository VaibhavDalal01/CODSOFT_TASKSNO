# Task 3 - Secure Code Assessment

## Overview

This project is a secure code assessment performed as part of the CodSoft Cyber Security Internship.

A Python-based user authentication application was selected for security review. The original application was manually analyzed to identify common security weaknesses and coding flaws. A secure version was then developed by applying recommended secure coding practices.

## Objectives

- Examine application source code for security weaknesses.
- Identify common coding flaws.
- Perform a manual security review.
- Document identified vulnerabilities.
- Recommend secure coding practices.
- Implement security fixes in an improved version.

## Technologies Used

- Python
- SQLite
- GitHub
- Manual Source Code Review
