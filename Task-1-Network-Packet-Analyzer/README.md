# Task 1 - Network Packet Analyzer

## Internship Project - CodSoft

A Python-based network packet analyzer that captures and analyzes network packets to display useful information such as source IP, destination IP, protocol, ports, and packet details.

## Features

- Captures network packets using Python
- Identifies common network protocols
- Displays source and destination IP addresses
- Displays source and destination ports when available
- Shows packet information in an organized format
- Provides packet payload/data inspection
- Includes basic error handling

## Technologies Used

- Python 3
- Scapy

## Installation

Install the required Python package using:

pip install -r requirements.txt

## Running the Project

Run the following command:

python packet_analyzer.py

Packet capture may require administrator privileges and a suitable packet-capture driver such as Npcap on Windows.

## Educational Purpose

This project was developed as part of the CodSoft internship program to understand network traffic, packet structures, protocols, and basic network analysis.

## Ethical Considerations

This tool should only be used on networks and devices where the user has explicit authorization to capture and analyze traffic.
